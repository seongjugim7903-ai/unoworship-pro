# 팀 페이지 — 초대 링크로 들어와서 만나는 곳

작성일 2026-08-09 · **아직 만들지 않았습니다.** 여기는 계획입니다.

---

## 왜 필요한가

지금은 초대 링크를 눌러 참여하면 **홈으로 떨어집니다.** 그런데 팀원이 링크를 누른
이유는 "그 팀에서 뭘 하려고" 입니다. 홈에는 그 팀의 것이 없습니다.

그래서 **참여를 마치면 그 팀 페이지로 들어가야** 합니다.

```
초대 링크 → 카카오 로그인 → (이름) → 그 팀 페이지
```

## 팀 페이지에 있을 것

카테고리에 따라 구성이 달라집니다. 지금 카테고리는 둘입니다.

| | 준비찬양 | 찬양대 |
|---|---|---|
| 자막협조 업로드 | — | ✅ |
| 악보 공유 | ✅ | ✅ |
| **악보 보기 · 미리 연습** | ✅ | ✅ |
| 게시판 | ✅ | ✅ |
| 악보마다 댓글 | ✅ | ✅ |

**가장 중요한 것은 악보 보기입니다.** 반주자가 아이패드·갤럭시 탭으로 열어 미리 연습하고,
예배 때도 그 화면을 씁니다. 연주용 악보 화면(`/worship/play`)이 이미 있으므로
**팀 페이지에서 그 화면으로 가는 버튼**을 크게 두면 됩니다.

## 이미 있는 것 — 다시 만들지 말 것

| 무엇 | 어디 |
|---|---|
| 연주용 악보 보기 (전체화면·발 페달·여백 잘라내기) | `features/worship-prep-ui/PlayViewer.tsx` |
| 준비찬양 입력 (곡·악보·조·템포) | `features/worship-prep-ui/WorshipPrepPanel.tsx` |
| 곡 라이브러리 | `lib/worship-prep/songLibrary.ts` |
| 찬양대 자막 요청 | `features/choir/ChoirRequestPanel.tsx` |
| 팀 소속·권한 판정 | `features/membership/` |

**팀 페이지는 이것들을 한자리에 모으는 껍데기**에 가깝습니다. 새로 만들 것은
게시판과 댓글뿐입니다.

## 새로 필요한 것

```sql
team_posts     (church_id, team, author, title, body, created_at)
team_comments  (post_id 또는 sheet 대상, author, body, created_at)
```

**댓글은 두 곳에 붙습니다** — 게시글과 **악보**입니다. 악보 댓글이 요청의 핵심이라
(`"악보마다 댓글"`) 대상 종류를 담는 칸이 필요합니다.

## 권한

팀 페이지는 **그 팀에 들어온 사람만** 봅니다. 안 들어온 팀은 목록에도 안 보입니다 —
잠금이 아니라 화면을 단순하게 하는 가림막입니다
([auth-church-scope](../auth-church-scope/context-notes.md) 참조).

| 누가 | 무엇을 |
|---|---|
| 팀 담당자 | 악보·곡 올리고 고치고 지운다. 게시글 관리 |
| 팀원 | 보고, 게시글·댓글 쓴다 |
| 교회 관리자 | 모든 팀 |

## 순서

**권한 검사를 자료 저장에 붙이는 것이 먼저입니다.** 지금은 담당자든 아니든 저장이
됩니다. 팀 페이지를 먼저 만들면 그 위에서 누가 뭘 할 수 있는지가 또 흐려집니다.

```
1. 권한 검사를 저장 경로에 붙인다        ← 다음
2. 팀 페이지 껍데기 + 이미 있는 것 연결
3. 게시판 · 댓글
```
