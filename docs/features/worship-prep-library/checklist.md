## 3단계 — 연주용 악보 보기

- [ ] 오늘 셋의 악보를 순서대로 넘기는 전체화면 보기 — **흰 배경 고정**
      → 검증: 곡 3개 셋에서 좌우 이동으로 끝까지 간다
- [ ] 넘김을 키 이벤트(`←` `→` `PageUp` `PageDown`)로 받는다 — 블루투스 발 페달이 그대로 동작한다
      → 검증: 키보드 방향키로 넘어간다
- [ ] 화면 꺼짐 방지 (Wake Lock)
      → 검증: 화면을 켜둔 채 방치해도 잠기지 않는다
- [ ] 셋 악보를 화면 진입 시 **한 번에** 미리 받기
      → 검증: 네트워크를 끊어도 이미 연 셋은 계속 넘어간다
- [ ] 모바일·태블릿에서 읽히는 크기
      → 검증: 실제 기기 폭에서 악보 글자가 읽힌다
