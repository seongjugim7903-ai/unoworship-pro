## 1단계 — 교회 스코프  ✅ 완료

- [x] `lib/authn/currentUser.ts` — 세션에서 로그인 사용자 읽기 (서버 전용)
      → 검증: 로그인 상태에서 user.id 가 나오고, 아니면 null
- [x] `lib/churchScope.ts` 를 요청 단위로 — 모듈 캐시 제거
      → 검증: 서로 다른 교회 사용자가 연달아 요청해도 섞이지 않는다
- [x] 소속 교회 조회 — `church_members` → 없으면 `profiles.church_id`
      → 검증: 소속이 없는 사용자는 폴백 교회로 떨어진다
- [x] **환경변수 폴백 유지** — 세션이 없으면 기존 교회
      → 검증: 로그아웃 상태에서도 지금 화면·현장 맥 읽기가 그대로 동작한다
- [x] `getActiveChurchName()` 도 같은 경로로
      → 검증: 설교자 자막 소속에 그 교회 이름이 들어간다

## 2단계 — 인증 강제  ✅ 코드 완료 · 스위치는 꺼둔 상태

- [x] 쓰기 라우트(POST/DELETE)에 로그인 요구 — 13개 핸들러
      → 검증: 강제 ON 이면 401 LOGIN_REQUIRED, OFF 면 지금과 동일
- [x] 읽기는 열어 둔다 — GET 에는 가드를 붙이지 않았다
      → 검증: GET 핸들러에 requireLogin 이 하나도 없다
- [x] 401 을 사람이 읽을 문장으로
- [ ] **`UNOWORSHIP_REQUIRE_LOGIN=1` 켜기** — 카카오 로그인이 붙고 한 번 로그인해 본 뒤에
- [ ] 현장 맥 디바이스 토큰 연결 (별도 작업)

### 왜 스위치를 두었나

지금 쓰는 분들은 로그인 없이 저장하고 있다. 카카오 로그인이 붙기 전에 강제를 켜면
그 순간 아무도 저장할 수 없다 — 주중에 켜지면 그 주 예배가 막힌다. 환경변수로 두면
배포 없이 즉시 되돌릴 수 있다.
