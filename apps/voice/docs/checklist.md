# 2단계 — 실시간 파이프라인 체크리스트

목표: **마이크 → STT → Detector → 이벤트**. 실제 음성으로 검출률·지연을 실측한다.
엔진은 Apple Speech(온디바이스) 우선, 어댑터 구조로 whisper.cpp 를 나중에 붙인다.

> 관문: 이 단계에서 목표 수치(지연 ≤0.6초, 오검출 0건)가 안 나오면 3단계로 가지 않는다.

## 2단계 — 실시간 파이프라인

- [x] `config/church.json` 실 사용 (본문·인용목록·성경경로)
- [x] 오디오 입력 열림 확인 — 48kHz, `ready` 이벤트 수신

      `tccutil reset SpeechRecognition com.unoworship.voice.stt` 로 초기화 후 재요청
- [x] **NSApplication(.accessory)로 전환** — 단순 RunLoop 는 앱이 "실행 중"에 머물러(독에서 계속 튐)

      운영 기계라 사운드 설정을 바꾸지 않는 게 원칙
- [x] 파이프라인 기동 확인 — `ko-KR · 온디바이스 · 48000Hz · 입력 BlackHole 2ch`
- [x] **지연 실측 — 평균 261ms · 중앙값 286ms · 최대 393ms (목표 600ms 대비 여유)**

### 현재 오디오 사정 (2026-07-28)

믹서(M32)·ATEM 모두 음성이 안 들어오는 상태라, **BlackHole 루프백으로 맥 재생 소리를 캡처**해
유튜브 설교 영상으로 검증한다.

| 장치 | 용도 |
|---|---|
| BlackHole 2ch | 맥 재생 소리 캡처 (현재 테스트 경로) · 사운드 출력을 BlackHole 로 두면 됨 |
| Blackmagic Design | ATEM USB 오디오 — 지금은 음성 없음 |
| (예정) Midas M32 | 후면 **USB-B** → 맥 USB-C. 클래스 컴플라이언트라 드라이버 불필요.
                     32채널이 각각 오므로 **AUX 분기 요청 불필요** — 목사님 채널만 골라 쓰면 된다.
                     음향팀에 Card Out 탭 포인트 **pre-fader** 만 확인 |
